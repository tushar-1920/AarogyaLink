Overview

AarogyaLink is a Flask-based rural health records platform. It provides QR-code-linked patient health records, doctor visit management, ASHA worker registration tools, and a Jitsi-powered telemedicine system.

Tech Stack
ComponentTechnology
Backend FrameworkFlask 3.1 + SQLAlchemy + Flask-Login
DatabaseSQLite (dev) / PostgreSQL (production)
FrontendJinja2 templates + vanilla CSS + vanilla JS

Architecture

The project follows a flat monolithic Flask architecture with Blueprint-based route separation.

# Project structure AarogyaLink/ ├── server.py # Gunicorn entry point ├── requirements.txt ├── Procfile ├── backend/ │ ├── app.py # Flask factory function │ ├── config.py # Configuration class │ ├── extensions.py # db, login_manager │ ├── models.py # SQLAlchemy models │ └── routes/ │ ├── main.py # Homepage, static pages │ ├── auth.py # Login, register, logout │ ├── patient.py # Patient CRUD │ ├── dashboard.py # Role dashboards │ ├── scan.py # QR scanner page │ ├── admin.py # Admin panel │ └── telemedicine.py # Online consultations └── frontend/ ├── templates/ # Jinja2 HTML templates └── static/ # CSS, JS, uploads, QR codes
Local Installation
Prerequisites

Python 3.11+, Git, a terminal. Works on Windows, Mac, and Linux.

# Clone and setup git clone https://github.com/tushar-1920/AarogyaLink cd AarogyaLink pip install -r requirements.txt # Run locally cd backend python app.py # Visit http://localhost:5000 # Default admin credentials Email: admin@aarogyalink.in Password: Admin@2025#Secure
Database

On first run, the app auto-creates all tables and seeds the admin account. No manual migration commands needed. SQLite database is created at /tmp/aarogyalink.db on Render or in database/aarogyalink.db locally.

Admin Setup

The admin account is auto-seeded on first startup. Admin can:

ActionURL
Admin Dashboard/admin/
Manage Users/admin/users
Verify Doctor/admin/user/<id>
Online Patients/admin/online-patients
View Analytics/admin/analytics
View All Patients/admin/patients
All Routes
Authentication
GET/auth/login
Login page for doctors, ASHA workers, and admins
POST/auth/login
Authenticate user. Redirects to role-specific dashboard on success.
GET/auth/register
Registration page for doctors and ASHA workers
GET/auth/logout
Logout and clear session
Patient Management
GET/patient/register
Patient registration form with voice input and camera
POST/patient/register
Create new patient. Generates QR code and PDF card. Accepts multipart form data with photo_data (base64) and doc files.
GET/patient/<id>
Patient profile page. Shows full history, QR, documents, visit timeline.
POST/patient/<id>/add-visit
Add a visit record. Requires doctor login. Fields: visit_type, hospital, diagnosis, prescription, notes.
GET/patient/search
Search patients by name, ID, village, or phone. Returns paginated results.
Telemedicine
GET/consult
Browse verified doctors. Filter by name, speciality. Shows availability.
GET/consult/doctor/<id>
Doctor public profile with available slots for next 14 days.
GET/consult/book/<slot_id>
Booking form. Step 1: symptoms and report. Step 2: payment screenshot upload.
GET/consult/video/<appt_id>
Jitsi video call page for confirmed appointments (patient view).
GET/consult/doctor/slots
Doctor slot management. Generate, toggle, and delete time slots.
GET/consult/doctor/appointments
Doctor's appointment list with payment verification controls.
